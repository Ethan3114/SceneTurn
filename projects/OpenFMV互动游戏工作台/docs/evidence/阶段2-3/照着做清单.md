# 阶段2-3照着做清单

## 连续首尾帧视频

1. 打开http://127.0.0.1:3210/zh-CN/editor?id=dbfe2c50-ad82-4044-b8a2-c3cc0be3576b，用原账号登录，点击“素材 → 生成素材”。在视频师区域找到“连续视频与候选”。
2. “纸艺连续首尾帧验证”保存四张实际图片、三个片段。第一段使用红色纸船和蓝色纸鹤，第二段使用同一张蓝色纸鹤和黄色纸风车，第三段使用同一张黄色纸风车和绿色纸盒。三段视频均已按本人确认实际生成，画面均为2秒、1280×720；预览显示媒体文件的实际时长，包含音轨尾部。
3. 视频状态与候选持续保存，切换页面后可以重新找回。三个原始候选均已采用到各自固定片段，可以直接播放实际文件。验证项目另保存实际拼接的较长候选和实际裁切的较短候选，用于核对替换与冲突。
4. 手动制作时展开“手动选择连续首尾图片”，按时间顺序选择项目中的图片。添加边界图片时自动增加对应视频片段，填写运动要求、时长、清晰度及目标，点击“保存连续视频序列”。每段点击“准备本段视频”，核对后点击“确认生成本段视频”。

## 候选与指定片段采用

1. 生成完成后，点击候选下方“检查并采用此候选”。预检显示候选实际时长、当前裁切需要覆盖的范围和目标片段。
2. 预检通过后点击“确认采用，保留现有编辑”。当前候选显示“当前已采用”。原片段的起点、裁切、播放速度、音量和互动保持，其他场景继续引用原素材。
3. 要得到新的候选，对同一片段再次点击“准备本段视频”，核对后逐次确认。已有任务、媒体和版本继续保留。

## 时长及文件冲突

1. 新候选不足以覆盖当前裁切时，出现“需要处理素材冲突”，显示实际可用时长和所需范围。当前片段继续使用已有素材，发布检查会阻止通过。
2. 使用现有场景时间线或本人Codex调整目标片段，再点击候选的“检查并采用此候选”，重新确认。本人Codex读取故事时可以看到授权场景的待处理素材采用和冲突。
3. 放弃本次替换时点击“保留当前版本”。候选和记录继续保留，当前片段保持，冲突关闭。
4. 实际媒体文件缺失或摘要变化时，采用被阻止。恢复原文件或重新选择素材后重新预检，原有内容继续保留。

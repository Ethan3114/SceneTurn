# 阶段2-2照着做清单

本阶段包含角色Agent、受控项目工具、共享记忆、人工接管和本人Codex连接。当前真实验收进行中，完成状态以是否表及完整verify输出为准。

## 打开工作台

1. 打开http://127.0.0.1:3210/zh-CN/account，用本人账号登录，进入项目列表并打开项目。
2. 在剧情编排中点击左侧“素材”，再点击“生成素材”。问问AI自动打开素材总监对话，画布按总监、编剧、角色、场景、分镜和视频分区展示本轮真实产物；声音岗位有本轮产物时显示对应区域。新一轮开始时清空展示，旧素材继续保存在项目及手动画布中。
3. 在“素材需求”中描述需要制作的内容，点击发送。总监分派岗位；当前岗位保存成果后暂停，对话中出现“等待你的确认”。逐项核对建议，可填写自己的答案或“需要调整的内容”。点击确认后继续；提交修改后由当前岗位重新交付。问题多于五项时分批询问。
4. 点击产物标题，看到对话框上方出现“产物名称 · 版本”，再输入修改要求。服务端会检查内容哈希，引用已更新时提示重新选择。刷新后对话、计划、任务及专业产物继续保留。
5. 图片制作前核对图片名称、尺寸及数量，点击“确认内容并生成图片”。岗位区域显示排队和实际图片；生成后点击“确认成果，继续制作”。三个账号各生成一项，额外任务保存到队列中。普通展示不包含生图提示词、来源依据及内部工具记录。分镜按连续边界帧显示，3段视频对应4张图片；视频确认卡展示实际首帧、尾帧和视频参数。
6. 点击“手动编辑画布”使用节点排布、图片切片、视频拼接或导入；生成的专业成果通过问问AI修改。点击“返回岗位展示”保存后继续对话。开发监控使用同一素材对话地址后的/developer接口，需要平台开发管理员权限。
7. 模型响应格式可恢复时，点击“继续当前任务”。文字请求状态待核实时，点击“重新尝试当前步骤”，核对可能重复计费、保留原预留和原费用上限，再点击确认；取消时继续保留暂停状态。商汤同步请求状态不明时，保留原请求及账号占用，后续重试需要单独确认。

## 总画布中的实际剪辑与互动

1. 在手动素材画布导入真实视频，选中视频节点，点击“加入场景时间线”。看到保存提示后关闭素材入口，点击顶部“问问AI”，进入本人Codex项目对话。
2. 指定场景，要求把视频从原片第1秒裁切3秒，放在场景第0秒。本人Codex通过项目工具保存编辑，可以进入场景时间线核对。
3. 要求添加普通按钮及QTE，明确出现时间、持续时长、成功场景和超时场景。本人Codex通过互动Skill操作真实button片段及click/timeout连接。场景总时长必须覆盖互动时间。
4. 点击“预览”，操作普通按钮和QTE，核对成功及超时分别进入指定场景。助手的工具校验检查保存结构，实际播放以本项为准。
5. 在素材对话中要求编写剧本及生图提示词，核对对应岗位区域中的完整产物。图片服务尚未配置时显示真实不可用状态。
6. 真实Flash工作流证明位于.intermediate/agent-smoke/c25f0100-536e-4a90-b45c-bf7564c0e590/，包含请求、完整保存项目、实际任务、Token与费用，以及服务重启证明。浏览器已核对普通按钮、QTE成功和QTE超时三条实际跳转。

## 核对专业创作产物

1. 选择“角色设计师”，任务写明需要制作的人物及用途。结果包含外观与服装锚点、一致性要求，以及每个人物的完整独立生图提示词。
2. 选择“场景设计师”或“分镜师”，核对空间、道具与镜头连续性。每套生图提示词分别包含主体、动作互动、场景、构图镜头、风格、光色、细节、避免项及输出规格；分镜还包含时长、动作和单独的视频运动要求。
3. 编剧、总监、影像、剪辑、互动和声音角色分别交付本岗位的完整专业字段。已有素材与待制作素材分别标明，创作补充写入假设，实际来源可检查。
4. 在授权文字节点或新建的结果文字节点查看完整正文。结构化对象、独立提示词、版本和哈希同步保存；手动修改正文后，核验会检查其与原专业产物是否仍一致。
5. 当前平台固定Flash，专业产物在岗位画布中查看完整正文。评分采用“符合要求、连贯性、来源使用、表达质量”四项，各1至3分：1不能接受，2可用，3满意。专业内容评分由本人确认。
6. 修订完整专业结构时，继续选择“完整专业产物”，勾选当前结果文字节点，明确需要调整的内容。助手读取原专业结构、当前版本和来源后修改具体字段，保存完整新候选、正文及提示词；画布标题、原稿及未涉及字段继续保留。

## 设定、来源与分支

1. 展开助手节点内的“项目记忆与来源”，选择“项目设定”或“本人决定”，填写人物、风格或创作要求并保存。这两类信息用于项目全局。
2. 选择“当前剧情事件”时，记录限于当前场景和选择的分支。合流场景可从“剧情分支”选择实际上游分叉。
3. 点击“读取设定与历史”，核对原内容，再点击“来源 · 版本”查看保存时的原文。原来源更新后会显示当前状态，完整历史继续保留。
4. 在互斥分支分别发起任务，检查其他分支独有事件是否仍带条件，核对当前场景使用的事实及来源。

## 人工修改与停止

1. 发起修改授权文字的任务，在运行期间自行修改目标并保存。
2. 检查旧版本写入被拒绝、自己的编辑保留；核对候选后选择“按当前版本继续”。
3. 点击“停止后续操作”，核对任务停止。该操作直接提交停止请求，未保存的画布编辑继续保留。
4. 保存并刷新画布，核对任务、记忆及目标内容。删除助手控制节点会保留任务历史，新增助手可以接管当前场景的这些历史任务。

## 本人Codex连接

1. 关闭素材入口，点击顶部“问问AI”，在本人Codex项目对话中点击连接，核对项目、工具范围及有效期。配对信息只填写在本机连接程序中。
2. 双击产品目录中的连接Codex.command，按终端提示确认默认本机地址、粘贴配对标识，并在隐藏输入框粘贴配对码。程序完成配对后持续运行，本节点连接列表显示“已连接”。程序使用本工程固定的官方Codex CLI 0.168.0，登录凭据继续由本人本机认证管理。
3. 配对后在项目对话中发送编辑要求，检查真实项目工具、线程与回合。项目Skill分别负责故事、排布、时间线、互动及核查。
4. 停止本机连接后检查等待状态；重新连接时核对原任务及原版本，确认没有重复修改或重复提交媒体。
5. 点击“撤销授权”，检查原连接的后续请求被拒绝，既有项目和结果保持可查看。

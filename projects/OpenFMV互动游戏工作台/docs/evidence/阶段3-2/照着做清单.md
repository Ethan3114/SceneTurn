# 阶段 3-2 桌面验收

1. 用 1280 和 1440 像素宽度的桌面窗口打开预览。从「我的项目」打开《裂盏》，进入故事画布。[预览入口](http://127.0.0.1:3210/zh-CN/projects)
2. 用 Tab 移到「试玩」并按 Enter。焦点进入播放窗口，按 Escape 退出，焦点回到「试玩」。在网页内核对普通按钮、QTE 成功和超时结局。
3. 在练习项目中用两个窗口打开同一场景，修改不同节点，依次点击「保存画布」。待出现保存提示后刷新，核对两个节点的修改。若两个窗口修改了相同内容，后保存的窗口会提示当前草稿已保留，另一窗口的修改可继续查看。
4. 打开「导出 → 项目备份与游戏导出」，核对备份与固定版本。打开同一备份做重复导入检查。游戏包在断网时仍可打开并走完两个分支。[1280 像素导出界面](项目备份与固定版本-1280px.png) · [1440 像素导出界面](项目备份与固定版本-1440px.png)
5. 核对角色动作、播放衔接和互动提示是否满足作品预期。

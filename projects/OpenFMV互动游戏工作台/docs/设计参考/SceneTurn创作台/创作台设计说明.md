# SceneTurn 创作台黑白设计

[Figma 创作台、剧情与素材对话](https://www.figma.com/design/1yAfX7nImYlNHvbRyegJ78?node-id=0-4) · [画板索引](../SceneTurn设计总稿/画板索引.json)

手动素材画布有十张桌面画板，覆盖文字、图片、视频、模型选择、拖线创建、混合参考、原片续写和生成核对。[Figma 手动素材画布](https://www.figma.com/design/1yAfX7nImYlNHvbRyegJ78?node-id=0-5)

节点标题、状态与菜单位于固定标题栏，媒体规格单独放在卡片底部。左侧端口接收可用输入，右侧端口提供可复用素材。生成节点内依次显示素材类型、生成功能和可编辑提示词，主要规格及执行操作固定在底部。小尺寸历史节点保留原有宽高，必要时可以滚动查看控件。布局使用 SceneTurn 自有节点样式，参考 LibTV 的素材连接方式及 Apple 桌面拖放规范。[LibTV 公开画布](https://www.liblib.tv/canvas/share?shareId=8h9jw9muu) · [Apple 拖放规范](https://developer.apple.com/design/human-interface-guidelines/drag-and-drop) · [Apple 弹出式按钮规范](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)

项目管理沿用首页的白底黑字，进入创作后切换为深灰工作区，剧照、分镜和视频保留原色。品牌栏、按钮、标签与边框在各页使用同一套黑白灰。高优先级的操作使用白底黑字，选中项同时有边框或标记。已连接、等待确认和异常状态用文字与图标说明，低饱和状态色仅用于辅助识别。[Apple 工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars) · [Apple 色彩](https://developer.apple.com/design/human-interface-guidelines/color)

| 界面 | 设计与操作 |
| --- | --- |
| 我的项目 | 白底项目空间集中提供最近编辑、创建、完整项目导入、素材库和作品馆。演示用《潮汐尽头》展示有封面时的样式，普通项目在缺少项目图片时使用中性图标。 |
| 剧情编排 | 深色画布放在中央，显示场景、分支与结局。打开「问问 AI」后，右侧停靠本人 Codex，对话与当前场景同时可见。手动编辑、配对和已执行事项都有清楚的入口和状态。 |
| 时间线 | 同屏保留素材、监视器和互动属性，下方为带时间刻度的轨道。普通按钮与限时互动沿用同一栏，清楚显示按键、时长以及成功和超时走向。 |
| 素材 | 在「项目素材」和「生成素材」间切换。生成素材左侧展示当轮岗位成果，右侧为总编对话，输入框下方提供「新一轮模型」。手动画布支持移动、连线和缩放素材节点。 |
| 视频确认 | 同屏比较首尾帧、镜头动作、运镜、声音及输出规格。确认操作位置固定，产品界面保留真实提交和费用授权规则。 |
| 模型设置和发布 | 模型设置提供文本、图片、视频的项目默认值和服务连接状态。导出从编辑器内打开，展示完整备份、可玩固定版本、公开范围和确认入口。 |
| 试玩 | 从编辑器打开当前场景，预览按钮出现与两条路线，随时返回编辑。 |

项目管理使用左侧导航。编辑状态通过顶部同一组「剧情编排／时间线／素材」切换，属性与对话在右侧分栏，为场景和轨道留出空间。主画板以 1440 × 900 为基准，另附 1280 × 900 项目入口检查窄窗口宽度。[Apple 侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)

## 原型中的操作

1. 在「我的项目」选择《潮汐尽头》的「继续创作」。点「问问 AI」查看本人 Codex 分栏，关闭后回到场景属性。
2. 点「时间线」，在右栏切换「普通按钮」和「QTE」，查看时长与后续场景的差异。
3. 点「素材 → 生成素材 → 新一轮模型」，切换文本、图片和视频，点击「应用到下一轮」后在输入框上方查看所选型号。关闭或取消会保留上次应用的选择。
4. 分别点「手动编辑画布」与「核对视频镜头」，查看节点画布和待确认状态。
5. 点「试玩」走向两个结局，或从顶栏打开模型设置、备份与固定版本。

## 模型选择

「新一轮模型」并排提供文本、图片和视频三个选择区，初始使用项目默认值。个人 Codex 与商汤 Fast、Seedream 5.5 同列为图片模型，选项显示本项目的连接状态。未连接或连接缺少生图能力时，该选项显示原因，并指向项目已有的「问问 AI」连接入口。

应用选择只影响下一轮制作。提交后，当前任务及续聊继续使用已保存的模型。项目默认值在「模型设置」管理。模型可用性由账号配置和当前任务所需的能力决定，固定首尾帧的制作仅提供支持两张边界图的型号。

已在 Figma 中实际切换文本、图片和视频型号，验证应用、再次打开及取消。项目默认面板展示模型目录及连接状态。原型中的生成、保存、连接和发布均为交互演示，网页接入进度见阶段开发文档。[阶段 3-1 开发文档](../../阶段文档/阶段3-1技术开发文档.md)

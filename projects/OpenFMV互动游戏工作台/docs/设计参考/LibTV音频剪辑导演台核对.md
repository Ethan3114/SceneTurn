## 本机音频模型

在音频节点中选择「音乐配乐」「音效」或「音色生成」，点击模型名称后可以选择当前账号的 ComfyUI API 格式工作流。服务连接本机 8188 端口。文字输入使用 `{{prompt}}`、歌词输入使用 `{{lyrics}}`，需要音频参考时在 LoadAudio 的文件输入使用 `{{referenceAudio}}`，保留一个 SaveAudio 输出。额外的本机模型节点由服务管理员通过 `OPENFMV_COMFY_TRUSTED_AUDIO_NODES` 明确登记。每个账号独立保存自己的三个工作流配置。

提交后可继续查询同一任务。只有 ComfyUI 返回终态并能取回真实声音时才会创建画布音频。配置、任务归属和请求标识保存在服务端，来源素材只允许来自当前项目。

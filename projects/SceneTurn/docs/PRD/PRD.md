## 1. 需求背景

将已有的无限画布和视频生成能力接入互动游戏制作流程，让创作者在同一个项目里制作素材、编排剧情和试玩作品。

## 2. 需求拆解

### 2.1 目标、用户与交付

| 维度 | 内容 | 依据与状态 |
|---|---|---|
| 目标 | 在 SceneTurn 中连接无限画布、共享项目记忆与 AI 素材制作，从视频脚本制作互动场景并发布上线 | V2 用户明确；全流程自主规划为目标，当前 AI 接入范围为素材制作 |
| 用户 | 产品经理本人，在线制作互动视频、分支故事和互动游戏 | 阶段0回答：满足本人在线制作 |
| 核心闭环 | 读取项目历史与当前分支 → 编写视频脚本和分镜 → 在画布生成素材 → 采用到场景 → 完成互动编辑与验证 → 云端保存 → 发布上线 | V2 用户明确；手动编辑与主动请求 AI 介入始终可用 |
| 交付物 | 本人使用的云端创作工作台、共享项目记忆、完整互动场景、在线作品、本地游戏导出及支付接口契约 | 按本人真实项目验证，发布固定版本并确认访问范围 |
| 边界 | 围绕现有游戏项目、创作画布、生成视频和场景使用建立完整制作过程；创作者决定生成内容与最终采用结果 | 需求草案；涉及自动采用的规则见 Q5 |
| 约束 | 保持已有游戏项目可读取、可编辑；创作数据全量保存；媒体任务串行执行，生成期间编辑可用；单次生成最高10元，本次模型验证累计最高300元，每月新增云费用最高100元 | 阶段0四项回答；达到预算上限停止新增收费请求 |

### 2.3 完整使用过程

| 步骤 | 用户操作 | 工作台应提供的结果 |
|---|---|---|
| 1 | 创建或打开游戏项目，选择需要素材的场景 | 展示当前项目、场景及已有时间线 |
| 2 | 进入素材创作画布，组织文字、图片和已有媒体 | 保留项目上下文，能够识别生成输入之间的引用关系 |
| 3 | 选择已配置的视频模型，设置其支持的生成参数并提交 | 展示可持续查询的生成任务，用户可以继续编辑其他内容 |
| 4 | 查看任务结果并播放视频 | 区分远端生成状态与本地文件保存状态，展示可用的产物 |
| 5 | 在当前剧情分画布选择生成结果并采用 | 使用进入分画布时确定的场景和目标片段，将视频写入相应时间线 |
| 6 | 编辑片段时长、播放顺序与互动按钮，连接故事分支 | 生成素材参与现有时间线编辑和互动预览 |
| 7 | 保存项目、关闭后重新打开，再导出游戏 | 画布与素材引用保持有效，导出的游戏能够独立播放 |

制作操作依次经过总画布规划、剧情分画布制作、时间线验证和发布确认。总画布保留游戏分支；每张剧情分画布绑定稳定的场景标识，生成任务同时绑定具体分镜或片段。上线前选择作品访问范围。

## 3. 功能需求

本节定义个人在线制作 MVP。具体实现须通过第5节的真实验收，支付部分按接口契约和未配置状态验收。

AI 通过结构化工具覆盖脚本、素材、场景编辑、验证和发布流程，用户可指定任务范围并随时手动编辑。文本自动执行，图片与视频逐次确认，最终发布单独确认。创作者连接本人电脑上的 Codex 执行创作任务。

### FR1 项目内访问无限画布

- 用户创建或打开 SceneTurn 项目后，能够在工作台进入项目关联的无限画布。
- 在画布、场景时间线和故事蓝图之间切换时，保留当前项目及已完成的编辑。
- 总画布管理游戏发展、场景及分支；每个剧情场景拥有自己的素材分画布，进入时固定所属场景。删除、复制及移动场景同步处理绑定关系，禁止遗留跨项目引用。
- 需求依据：用户提出接入无限画布并打通制作工作台。验收：AC1、AC3。

### FR2 使用画布组织生成输入

- 用户能够创建、编辑和移动创作节点，组织提示词、参考图片及已有媒体，并建立生成所需的引用关系。
- 素材创作沿用原AI Studio的画布交互：文字在文字节点内编辑，提示词与生成参数在生成节点及其附属面板内编辑，拖动节点连接端点组织引用。报价确认、任务进度、结果预览与采用操作均属于相应画布节点。
- 配置节点按连入的创作内容组装生成输入，生成结果以关联的独立媒体节点保留；当前项目、场景、任务及素材标识贯穿输入、确认与结果采用。
- 用户能够将项目已有的兼容素材用于画布，也能够将画布生成的可用媒体用于项目。
- 画布引用关系用于确定生成输入；故事蓝图连接用于确定播放分支。编辑任一关系时，另一关系保持其原有含义。
- 需求依据：已有画布能力与打通目标。验收：AC1、AC2。

### FR3 配置文本与媒体生成能力

- 用户能够配置生成视频所需的服务地址、凭据和模型，识别模型支持的输入及参数。
- 文字生成通过平台服务端DeepSeek API执行，默认deepseek-flash；平台管理员配置API凭据，注册用户使用平台提供的创作功能与Token计费体系。凭据仅由后端读取，普通用户无法读取或修改平台凭据。
- 生成节点按原端侧AI-Studio提供剧本摘要、角色画像、道具提示词、场景说明、分镜情节、单镜提示词，以及角色图、道具图、场景图、单镜画面、分镜视频和拼接成片。输入、引用与参数位于节点内部，结构化结果保存为独立节点。图片支持自定义网格切片并保存来源关系。
- 生成表单根据所选模型展示必要输入；缺少参考图片、凭据或其他必填内容时，指出具体缺失项。
- 图片沿用无限画布的模型配置与选择方式；视频优先接入阿里云 Wan，服务地区、模型标识、输入形式及参数按实际账号能力验证。现有其他供应商的 Wan 接口需要单独适配。
- 现有代码的默认模型、固定时长和清晰度作为实现参考；产品可调整参数以确认后的模型能力为准。
- 需求依据：补充视频生成能力。验收：AC2、AC9。

- 文本生成在用户发起的创作任务范围内自动执行；图片和视频的每次生成请求须取得用户确认后提交。
- 确认时展示目标、提示词、参考素材、模型、参数和生成数量，以及可取得的费用估算。输入或数量变化后重新确认。
- 费用确认在发起生成的画布节点中展示实际冻结输入，确认后该节点持续展示任务状态，结果媒体节点提供播放及固定片段采用入口。
- 确认记录与任务持久保存；刷新、重启和重复点击不能重复提交。同一远端任务的查询、下载不产生新的生成请求。
- 当前开发验证使用本人配置的服务商账号，文本与媒体单次生成最高10元、本次模型验证累计最高300元；提交前检查已发生费用与待执行费用预留，超限停止新增请求。本人Codex订阅或自付费用与平台API费用分别展示。

### FR4 提交并跟踪视频生成任务

- 用户提交生成请求后，能够查看准备提交、提交结果待核实、远端处理中、下载中、本地可用或失败等实际状态。
- 每个任务保存所属项目、来源画布节点、固定关联场景与目标分镜或片段、生成输入与参数、服务商、远端任务标识及结果。
- 用户切换页面或场景时，已提交任务继续被跟踪；重新打开应用后，能够识别并查询已有远端任务。
- 提交结果不明确或查询中断时，先核实原任务状态；重新查询与重新生成在界面中使用不同操作，避免重复提交。
- 媒体生成任务按提交顺序串行执行，同一时刻最多一个媒体生成任务进入供应商处理；等待顺序和当前状态持久保存，界面编辑与已有任务查询保持可用。
- 需求依据：异步生成过程与数据保持要求。验收：AC2、AC4、AC9。

### FR5 接收并保存生成视频

- 远端生成完成后，云端取得视频文件并保存至对象存储，确认文件可读取、媒体信息可识别，再标记为云端可用；本地下载另行记录缓存状态。
- 素材记录包含稳定标识、视频文件引用、真实时长、尺寸、格式及生成来源；封面按可取得的媒体信息保存。
- 下载失败、磁盘空间不足或项目保存失败时，展示发生问题的环节，保留任务与远端结果信息，允许继续获取或保存已有结果。
- 本地已保存的生成素材在无供应商连接的情况下仍可播放和编辑。
- 需求依据：生成视频进入现有本地制作流程。验收：AC2、AC5、AC9。

### FR6 预览并选择生成结果

- 用户能够播放生成视频，并识别其来源提示词、参考素材、生成参数和状态。
- 用户能够明确选择用于游戏的结果；生成完成后的采用行为遵循 Q5 确认的规则。
- 多次结果作为候选版本保存，用户选择采用结果；Agent 可在用户指定的任务范围内采用明确结果。被引用的版本禁止直接删除，删除前展示并解除相应引用。
- 需求依据：生成结果进入场景前的选择需求草案。验收：AC2、AC3。

### FR7 将视频用于指定场景

- 用户能够将选定的可用视频用于明确指定的场景时间线，识别目标场景和采用位置。
- 时间线片段与画布结果引用同一份已保存素材，媒体时长及来源信息正确。
- 生成期间切换项目或场景后，产物仍归属原项目；采用时重新核实目标，避免写入其他项目或场景。
- 目标场景或目标片段已删除时，结果保留在所属项目中，用户能够重新选择采用位置。
- 新分镜使用预先分配的片段标识插入；重新生成只替换目标片段的素材引用，其他场景引用保持原版本。替换保留原起点、裁切区间、互动时间与分支；新媒体不足以覆盖已有区间时标记冲突，完成调整前阻止发布。更长媒体使用既定裁切范围，用户可手动修改。候选版本和来源继续保留。
- 需求依据：用户要求打通视频生成与互动游戏制作。验收：AC3、AC9。

### FR8 继续编辑和预览互动游戏

- 采用视频后，用户能够继续编辑场景媒体、普通按钮、QTE 和故事分支，并运行互动预览。
- 采用素材时，原有互动片段、时间设置和故事连接的变化范围应明确；超出新视频有效时间的内容需要提示用户处理。
- 生成任务完成和素材保存期间，用户对其他场景进行的编辑能够保留。
- 需求依据为现有互动编辑能力。验收见 AC3、AC6。

### FR9 统一保存并恢复项目

- 项目保存内容包括故事结构、场景时间线、画布内容及引用关系、项目素材、生成任务与产物关联。
- 保存成功后，关闭并重新打开项目，能够继续查看和编辑上述内容。
- 项目中引用的素材使用可随项目保存的文件关系；项目目录移动及跨环境使用的范围依 Q6 确定。
- 用户能够发现失效素材及其受影响的场景或画布节点，并重新指定文件。
- 保存过程中发生的新编辑能够保留；保存失败时保留未保存状态并说明失败原因。
- 脚本、对话、画布、记忆、任务、候选素材、原始媒体和发布版本全量保存，不设置自动过期清理。存储用量计入云费用估算；接近预算时提示本人并停止新增会产生费用的操作，已保存内容继续保留。
- 需求依据：两个现有项目保存方式不同，需要完整保持创作成果。验收：AC4、AC5、AC6、AC9。

### FR10 兼容已有游戏项目

- 用户能够导入已有的互动项目，继续使用故事节点、连线、媒体片段和互动数据。
- 现有项目首次使用画布时，建立与该项目关联的创作数据；保存后能够再次打开。
- 项目格式更新需要保留原有数据；读取或转换失败时说明原因，保留原文件供用户继续处理。
- 导入现有无限画布中的视频项目，保留节点、连接、分镜顺序、提示词、参考媒体、生成结果及来源。导入预览建立源标识到场景、分画布、素材的映射，确认后写入云端；缺失媒体和无法转换的数据明确列出并阻止不完整导入成功。重复导入同一版本不重复创建素材。实际项目数据需从原应用存储或完整导出取得，源代码目录不能替代项目数据。
- 需求依据：整合现有项目的兼容要求。验收：AC7。

### FR11 导出含生成视频的互动游戏

- 用户能够按现有游戏导出流程，将已采用的生成视频及播放所需素材纳入游戏包。
- 导出内容保留时间线播放、普通按钮、QTE 和故事分支行为。
- 游戏包能够使用包内素材播放；凭据、供应商鉴权信息与本机生成配置保持在创作环境中。
- 缺少必要文件、复制失败或写入失败时，指出失败原因及受影响素材，停止将该次导出标记为成功。
- 需求依据：打通后的视频需要参与原有完整游戏交付。验收：AC8、AC9。

### FR12 展示异常与继续操作入口

- 区分输入不完整、服务配置错误、生成失败、查询中断、下载失败、本地保存失败和目标失效。
- 错误发生时立即展示具体环节，停止依赖该结果的后续操作，并保留用户输入及已有成果。
- 继续查询、重新下载、重新保存和重新生成分别作用于对应环节；产生新生成请求的操作由用户明确触发。
- 需求依据：保证生成与采用过程可以理解和继续处理。验收：AC9。

### FR13 共享项目上下文记忆

- 脚本 Agent 共享项目级记忆，记录脚本、分镜、角色与场景设定、已生成和已采用素材、故事事件、操作结果及用户修改。
- 每条记忆带来源对象、版本、时间、适用场景和剧情分支；区分实际采用内容、创作候选和已失效内容。
- 编写后续分镜时按当前项目、场景及分支提取相关历史，展示采用了哪些来源。相互排斥的故事分支保持隔离。
- 用户修改设定或脚本后，后续任务读取最新有效版本；受影响的已有分镜与素材标记待检查，禁止无提示地批量重生成。
- 完整历史持续保存，单次模型输入按相关性与容量选取；历史摘要保留原始来源，允许检索原文。
- 验收：AC10、AC11。

### FR14 手动编辑与 Agent 操作共用项目能力

- 当前通过画布完成 AI 素材制作，用户随时能够手动修改或请求 AI 介入。
- 检查 Codex CLI 与画布已有接口，通过结构化工具读写项目、组织生成输入和跟踪任务；交互操作使用项目 API 或工具调用。
- 人与 Agent 使用同一项目版本和变更记录。Agent 提交操作时检查目标版本；用户期间修改了相关内容时，重新读取并调整待执行操作。
- 用户能够查看任务计划、执行结果并停止后续操作；已提交远端生成的实际状态继续保存。
- 创作者安装本地连接程序并连接本人 Codex，授权限定账号、项目及工具范围，支持撤销。云端记录任务与共享记忆；本机离线时暂停需要 Codex 的步骤，已提交媒体任务由云端继续查询与保存。重新连接后检查版本与授权再继续，不重复提交。自连 Codex 的模型费用由创作者自行承担。
- 全流程规划工具涵盖脚本、分镜、素材、互动场景、验证和发布；当前开放执行的阶段及预算以授权记录为准。
- 验收：AC11、AC12。

### FR15 云端保存与跨会话继续

- 项目结构、共享记忆、任务状态和媒体文件必须保存到云端；界面区分本地已保存、上传中和云端已保存。
- 重新登录或在授权设备打开项目后，能够恢复当前版本、历史上下文、已采用素材与未完成任务。
- 云端按用户及项目权限隔离访问。模型调用前检查上下文读取权限，写入、下载及发布均检查目标项目权限。
- 本地缓存保留可用素材；云端写入失败时显示未同步状态。多端修改通过版本检查发现冲突，防止覆盖用户修改。
- 验收：AC10、AC11、AC13。

### FR16 从脚本到线上互动场景

- 一次完整制作从视频脚本开始，包含分镜、生成素材、场景时间线、互动按钮或 QTE、播放验证及上线发布。
- 发布记录固定项目和素材版本；发布前验证文件可访问、场景入口与分支可达，以及实际播放器行为。
- 用户能够获得线上访问地址并验证作品。发布失败保留可诊断状态，正在使用的发布版本保持可识别。
- 工作台部署云端，作品支持在线播放和本地导出。每次发布展示固定版本、检查结果和公开范围，须创作者确认；内容或公开范围变化后重新确认。发布失败保持已有可用版本。
- 验收：AC14。

### FR17 注册、登录与作品访问

- 实现真实注册、登录和退出登录。使用已确认的邮箱与密码注册、HttpOnly Cookie会话。每条业务记录从第一张表起带所属用户与项目，服务端逐次校验权限。
- 使用规模按本人在线制作验收；注册账号分别管理自己的项目、私有媒体、对话和供应商配置。使用本人控制的两个真实账号验证数据隔离。
- 作品公开性由所属账号决定；私有作品的播放清单及媒体请求均校验权限。
- 公开作品只开放该发布版本的播放内容，创作对话、草稿、项目记忆与供应商配置继续受项目权限保护。撤销公开后停止新的未授权访问，已经下载的内容无法收回。
- 验收：AC16。

### FR18 Token计量、费用记录与支付扩展接口

- 记录本人媒体调用的模型、输入参数、报价依据、费用预留、实际用量及费用；生成确认绑定最大允许费用。查询和下载复用原任务记录。
- 商业目标包含平台Token销售。文本任务保存DeepSeek返回的输入、缓存命中、缓存未命中、输出和总Token，以及真实请求标识、冻结价表与供应商成本。平台销售价格与供应商成本分别配置和记录，同一请求只能结算一次。
- 当前按本人开发验证规模执行，销售价格与支付渠道保留配置接口。销售策略未配置时，普通注册账号的收费文本请求返回明确的未配置状态；管理员开发验证仍受单次和累计预算约束，不创建虚构余额或支付记录。
- 单次生成最高10元，本次模型验证累计最高300元，每月新增云费用最高100元；达到上限停止新增收费请求，已发生或供应商尚未确认的费用按任务持续核实。
- 保留支付能力查询、创建订单、查询订单、支付通知及退款的扩展接口，定义请求、响应、错误与操作唯一标识。未配置支付渠道时，能力查询返回实际未配置状态，资金操作返回统一的PAYMENT_NOT_CONFIGURED错误。
- 本人通过自己的模型服务账号承担实际模型费用；支付扩展接口的未配置状态独立于个人媒体生成。验收：AC17。

### FR19 全量创作历史与数据用途

- 脚本、对话、记忆、工具结果、任务、素材候选及发布记录作为本人创作数据全量保存，并支持跨会话读取和历史导出。
- 创作历史用于本人的项目记忆和连续制作。独立的产品改进与训练授权保持关闭，保存历史与授权利用分别记录。
- 自动清理策略为关闭。显式删除已有项目、素材或历史需要本人确认，并检查引用关系。
- 验收：AC18。

## 4. 边界与红线

- **创作控制：** 用户能够识别当前项目、目标场景和素材采用结果；自动采用、批量修改或替换共享素材的规则以 Q5 的明确决定为依据。
- **数据保持：** 任务完成、页面切换、项目保存及格式更新均需保留已有故事、画布、时间线与素材数据。跨项目写入时检查所属关系。
- **结果真实性：** 远端任务成功、本地文件可用、场景采用完成和导出成功分别记录，界面状态必须对应实际结果。
- **费用控制：** 提交状态不明确时核实已有任务；重复查询不触发新生成。额外生成请求和费用阈值按 Q3、Q7 的确认规则处理。
- **凭据保护：** 自连 Codex 凭据保留在本机，平台媒体凭据由云端受控保存；日志、项目文件和游戏包不得包含凭据。上传参考内容前，用户能够识别所选模型及参与生成的素材。
- **失败处理：** 失败立即可见，依赖步骤停止；保留已有输入、任务标识和成功产物，允许用户处理具体失败环节。
- **真实验收：** 视频生成采用真实服务请求与可解码文件验证，项目恢复和游戏导出通过实际保存、重新打开及播放验证。

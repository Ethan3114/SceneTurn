# 阶段2-4照着做清单

## 试玩《裂盏》

用原账号打开[《裂盏》编辑器](http://127.0.0.1:3210/zh-CN/editor?id=42ddc399-3985-443a-9962-ea10bb3fc367)，点击顶部「试玩」。看完「夜试斗气」后选择「停手守气」进入「稳住斗气」，或选择「强行催气」进入「裂盏失手」。使用「重试这场练习」回到「夜试斗气」查看另一条线路。

## 打开本人账号下的网页游戏

打开http://127.0.0.1:3210/zh-CN/play/63be4036-0514-5fa9-a76a-9fb0b1610966?version=e0dc19ad-5146-4ec4-bd43-207b1969edf3，用原账号登录。游戏使用三段实际Wan成片，包含普通按钮、QTE成功与超时分支。点击“继续”开始，直接在前端页面完成游玩。

编辑和试玩入口为http://127.0.0.1:3210/zh-CN/editor?id=63be4036-0514-5fa9-a76a-9fb0b1610966。

## 直接在前端页面游玩

1. 在编辑器顶部点击“试玩”，直接运行当前项目。点击“继续”，再点击“进入第二幕”；出现“及时选择”时点击，进入第三幕并到达“完成结局”。点击“退出”返回编辑器。
2. 回到“我的项目”，点击项目卡片的“在网页游玩”，直接进入完整游玩页面；进入第二幕后等待QTE结束，应到达“超时结局”。点击“退出”返回项目列表。
3. 打开编辑器顶部“导出 → 项目备份与固定版本”。在已完成的私有游戏版本记录中点击“在网页游玩”，进入前端固定版本页面。
4. 核对页头的版本号，完成普通按钮及QTE分支操作。点击页头“重新开始”重新游玩；刷新后保持同一固定版本；点击“返回编辑”回到项目。
5. 上述流程均在网页中直接完成。新版本可以通过“生成网页可玩版本”检查并确认，完成后出现游玩入口。

## 保存完整备份

点击“备份完整项目”，完成后点击“下载项目备份”，用于恢复项目、媒体、画布及来源历史。已有游戏包下载保留在完成记录的展开项中。

## 导入与恢复

1. 回到「我的项目」，展开「导入与恢复完整项目」，选择完整 ZIP。支持互动项目、无限画布第 3 版导出及 SceneTurn 备份。
2. 等待检查完成，核对项目名称、场景数、节点数、媒体数和来源映射。出现缺失项或无法转换的节点时，补齐文件并重新上传。
3. 点击“确认导入”，完成后点击该记录中的“打开”进入独立项目，核对视频、按钮、连线和素材画布。
4. 再次上传同一文件，核对返回同一导入记录及项目。相同内容重新打包后导入，也会复用既有项目及已登记素材。
5. 关闭页面后重新打开，导入、备份和固定版本记录应当保持。修复无法写入的目录或缺失成品文件后，可点击“重新生成此版本”。

## 导入验收依据

本阶段使用了源互动编辑器保存的完整项目和无限画布导出的完整视频项目验证兼容性。实际文件、媒体和连接均通过检查。也可使用 SceneTurn 完整备份检查导入与恢复步骤。

# SceneTurn 桌面验收

1. 打开 [SceneTurn 首页](http://127.0.0.1:3210/zh-CN)，向下滚动查看「AI 生成素材」和「Codex CLI 编排与互动」。顶部菜单百分比随滚动更新，点「体验观众选择」进入《潮汐尽头》。分别点「点亮信标」和「关闭闸门」，核对两个结局和重选。点顶栏「功能」切换四张工作台截图，滚动到「常见问题」展开和收起问答。作品馆在页尾，创作台在右上角。
2. 登录后打开[《裂盏》编辑器](http://127.0.0.1:3210/zh-CN/editor?id=42ddc399-3985-443a-9962-ea10bb3fc367)。点击「试玩」，让「夜试斗气」播放到选择，分别选择「停手守气」和「强行催气」。第二条线路可通过「重试这场练习」回到开场。
3. 在编辑器打开「素材 → 生成素材」。左侧可切换剧情场景、查看三列岗位卡片或进入手动编辑，右侧是固定对话区。点输入区的「新一轮模型」可分别选择文本、图片和视频。应用后，输入区显示已选型号，取消时保留已应用的选择。当前任务的续聊沿用原型号。等待确认的镜头可点「核对视频镜头」，看实际首尾帧与规格，再决定是否提交。
4. 打开[模型设置](http://127.0.0.1:3210/zh-CN/settings/models)，选择项目，核对文本、图片和视频模型。已配置的模型根据权限与任务能力开放。需要补充供应商账户配置的模型显示原因。
5. 项目连接支持图片生成的 Codex 后，在「新一轮模型」的图片分栏选「个人 Codex」。在总编对话发起新一轮，核对岗位生成方案后确认使用个人账户。实际图片通过原连接回到岗位成果和项目素材。
6. 如需公开自己选定的作品，在本人项目的「导出 → 项目备份与固定版本」确认固定版本，选择「公开至作品馆」。用未登录窗口打开返回的作品链接，先在[作品馆](http://127.0.0.1:3210/zh-CN/works)搜索作品，再从详情进入影院。撤下后刷新，作品与媒体停止公开访问。
7. 在「素材 → 生成素材 → 手动编辑画布」从左侧添加一个文本节点。填写镜头描述，把右端拖到空白处，在下游菜单选择「图片生成」。点选图片节点，从下方生成器改提示词、模型、比例和像素尺寸。保存并刷新，核对节点和连线。图片服务已配置时，可以打开核对卡。
8. 导入一段 1 至 15 秒的 MP4、两张项目图片，再添加本段镜头文字。把四项素材连到同一个万相 3.0 节点。选「全能参考」指定原视频并选用两张图。键入 `@` 点名素材，打开视频核对卡确认原视频、图1、图2和镜头文字。点击「返回编辑」，切换「首尾帧」后从同一批连线指定首帧与尾帧。已保存的旧编辑任务可按原执行方式核对。
9. 在画布中选择「脚本 → 脚本」，点击「自己编写分镜脚本」录入时长、画面、动作和对白。保存画布后刷新并重开脚本，核对原内容。打开左下角「资产管理」检索节点，在画布上方的「工作流」与「故事板」之间切换。停留在卡片附近可查看端点，悬停连线可查看变化。[Figma 登录态原图](https://www.figma.com/design/1yAfX7nImYlNHvbRyegJ78?node-id=19-15)
10. 从图片生成卡右端拖线到现有视频卡左端，也可点击已上传图片的右端，选择「视频生成」。视频卡会采用图像输入，尚未生成的图片会保留连线并提示等待。点击空白关闭设置，再点卡片正文或标题，核对原提示词。直接拖动时两张卡随视野一起移动，长按一张卡再拖动时只有该卡移动。

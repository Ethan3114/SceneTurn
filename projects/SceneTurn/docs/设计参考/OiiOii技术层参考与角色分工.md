## 角色与工具

角色定义包含任务输入、允许写入的对象、可调用工具和完成条件。按用户任务选择所需角色，顺序执行；平台API请求记录角色、任务、真实usage、冻结价格版本及供应商预估成本。

| Agent角色 | 负责的结果 | 允许使用的工具 |
| --- | --- | --- |
| 创作总监 | 项目要求、创作计划、任务分配、受影响步骤与人工接管 | 读取项目、读取分支上下文、查询能力与预算、提交任务计划、派发角色任务、请求必要补充、查询状态 |
| 编剧 | 剧本、对白、人物关系、剧情分支及选项意图 | 读取创作要求与已有剧情、生成及修订结构化剧本、保存带来源的记忆、提交局部修改 |
| 角色设计师 | 角色描述、确认主图、服装与造型规范、三视图引用 | 读取角色设定、编写图像要求、申请图片报价、查询候选、提交采用请求、保存角色素材引用 |
| 场景设计师 | 场景与道具说明、光线及风格规范、场景和道具参考图 | 读取场景与道具设定、检索项目素材、申请图片报价、查询和采用候选、保存场景及道具引用 |
| 分镜师 | 镜头清单、景别与动作、预计时长、角色及场景引用、镜头输入要求 | 读取剧本和确认素材、拆解镜头、检查引用、保存镜头计划、创建带类型的画布节点与连接 |
| 影像制作师 | 对应镜头的图片或视频候选及实际媒体信息 | 读取固定镜头输入、查询支持的模型能力、申请图片或视频报价、查询已确认任务、核查真实媒体、提交候选采用请求 |
| 剪辑师 | 场景媒体轨、片段顺序、裁切、转场和成片 | 读取实际媒体时长、修改指定片段、执行切片和拼接、检查时长冲突、预览与验证时间线 |
| 互动设计师 | 普通按钮、QTE、触发条件、变量和剧情分支连接 | 读取场景与剧情分支、编辑NodeTimeline v2互动轨、检查目标与条件、运行互动预览及分支可达性检查 |
| 声音设计师 | 对白配音、背景音乐、音效与场景声音安排 | 读取对白与实际时长、检索和导入真实音频、编辑声音片段与混音安排；模型生成工具按实际服务配置与费用确认使用 |

角色通过平台API完成模型调用，真实Token与供应商预估成本进入统一账目。平台售价、余额及收款策略未配置时保持未配置状态。原PRD中的本人Codex连接作为独立连接能力保留，其权限与项目工具使用同一套服务端检查；只记录可核验的本机用量及本人账户费用，无法取得的数据标记未知，不使用平台API价表计算Codex费用。

现有功能入口按职责归属：剧本创作与剧本摘要交给编剧；角色画像交给角色设计师；道具提示词与场景说明交给场景设计师；分镜情节与单镜提示词交给分镜师；图片切片与视频拼接交给剪辑师。图片、视频生成由对应设计角色提出要求，影像制作师调用实际媒体工具。

## 工具执行约束

工具按职责分为项目与上下文、创作与编辑、媒体、任务控制、费用与确认、质量检查六类。每个工具定义Pydantic请求与响应，使用固定工具名称及允许的参数。

- 项目读写：验证owner_id、project_id、scene_id及expectedRevision；使用operationId防止重复写入。角色只能修改本次任务授权的对象和字段。
- 上下文检索：同时限制项目、场景、分支和版本，返回来源及稳定引用。相互排斥的分支分别检索。
- 任务控制：持久保存计划、角色、输入引用、依赖、状态、结果、错误和人工确认。重复的完成通知读取原结果，服务重启后核对原任务状态。
- 图片与视频：Agent提出带固定目标和输入的生成请求，服务端形成报价；本人确认后才提交。变更输入、参考、模型、参数或数量需要重新确认。
- 费用：工具读取服务端价表与预算，平台API保存真实用量及供应商预估成本，实际账单取得后另行核对。模型输出不能修改单价、余额、支付状态或已发生费用。
- 编辑与接管：人工编辑与Agent写入共用项目版本。旧版本操作返回冲突，保留模型结果与人工修改；重新读取后只提交受授权的局部修改。
- 质量检查：结构、引用、类型、时长、媒体可读性和互动目标使用确定性检查；叙事与美术质量按本人真实样例评分。

## 共享上下文

各角色读取同一项目的带版本资料，并用稳定ID关联产物。角色交接传递引用及版本，接收角色通过受控工具取得所需内容。

| 对象 | 必要内容 |
| --- | --- |
| 项目要求 | projectId、revision、目标时长、比例、语言、风格、任务范围及预算 |
| 剧情与分支 | sceneId、branchId、剧本版本、对白、角色出场、选项与分支条件 |
| 角色与场景设定 | characterId、locationId、propId、文字设定、确认素材assetId、来源与版本 |
| 镜头计划 | shotId、sceneId、branchId、角色/场景/道具引用、图片输入、视频输入、预计时长与真实时长 |
| 媒体候选 | assetId、generationId、输入摘要、实际MIME、尺寸、时长、字节数、哈希及采用记录 |
| 执行与确认 | taskId、role、依赖、状态、operationId、确认摘要、价格版本、实际Token与费用 |
| 项目记忆 | 内容、来源对象、来源版本、所属场景和分支、作者角色及更新记录 |

模型不能自行编造可用素材地址。下载和模型输入使用通过所属关系检查的真实assetId及受控媒体服务。历史版本与候选保留，重新制作建立新任务和新版本。

## 当前开发安排

- 本轮完成工具栏三个快捷入口移除及节点选择、删除验证，节点内部的创作功能继续保留。
- 阶段2-2依据本分工完善任务编排、角色权限、共享记忆、版本冲突和人工接管，以及已规划的本人Codex连接。
- 阶段2-3接入实际图片及参考图片视频能力，相应角色调用真实媒体工具，逐次确认费用。
- 脚本生成后先生成图片，再使用图片制作视频；完整生成顺序在正式工作台收尾时集中梳理和验收。本轮保持现有生成顺序代码。

模型清单、RAG风格库、音频供应商和角色名称均按本产品实际能力配置；新增收费资源沿用已确认预算及创建前确认规则。

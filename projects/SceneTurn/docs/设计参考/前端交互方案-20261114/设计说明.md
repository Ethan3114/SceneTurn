# 前端交互方案

[Figma设计稿](https://www.figma.com/design/oAGz5eyJuo21csgeY9gf1g?node-id=1-7) · [素材交互原型](https://www.figma.com/proto/oAGz5eyJuo21csgeY9gf1g?node-id=1-3&starting-point-node-id=1%3A3&scaling=min-zoom)

素材制作由问问AI的对话承接，艺术总监负责梳理需求和岗位分派。编剧、角色设计师、场景设计师、分镜师及视频师通过带版本的产物引用接续工作，各岗位在画布上拥有专属展示区。点击产物可引用到对话提出修改；图片和视频在对话中确认输入与规格，后台保留预算约束。

优先审阅03总监梳理需求、04脚本和分镜交接、07岗位产物展示、09引用产物修改。素材区域之外的剧情编排、本人Codex编辑和手动剪辑维持既定设计。

参考：[OiiOii自由画布](https://www.oiioii.ai/zh/features/canvas)及本人提供的角色展示区截图。设计稿中的作品与任务状态是交互示例，预览操作不调用模型、不修改项目；图像沿用本项目已有素材。

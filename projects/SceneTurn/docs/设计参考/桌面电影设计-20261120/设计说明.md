# 桌面电影设计

[Figma 页面设计](https://www.figma.com/design/vA2rRRnUdxnYdJnkG1m97D?node-id=1-2)

| Figma 页面 | 设计范围 |
| --- | --- |
| 01 作品首映与影院 | 首页首映、作品馆、作品详情、正片开场、分支与 QTE、两个结局和访问受限 |
| 02 项目、剧情与剪辑 | 项目、完整导入、剧情总画布、本人 Codex、时间线、固定版本交付、登录注册 |
| 03 素材制作 | 各素材入口、岗位成果、边界帧、逐段确认、候选采用、结果待核实、手动画布、切片与拼接 |
| 04 设置与文档 | 生成服务、账户、Codex、用量、开发记录、隐私和条款 |

共 39 个可编辑静态画板。展映用《潮汐尽头》的电影剧照展示作品封面、章节、选择与结局，工作台按 Apple HIG 保留明确的导航、工具栏、分栏与确认。作品馆展示获创作者许可的可玩固定版本。四张剧照来自内置图像生成，用于这次页面设计；画板中的《潮汐尽头》与其他作品为视觉示例，《裂盏》用于实际流程验证。

已核对 Figma 的四个页面，选中首映画板确认尺寸为 1440 × 1625。样式、文字与剧照分别在设计图层中，文件中包含 1084 个文字层和四张原创剧照。

设计以作品为首页内容，使用宽幅影片预览和独立的作品入口。导航、工具栏和分栏参考 Apple 的设计指南。[OiiOii](https://www.oiioii.ai/zh/) · [Apple HIG 品牌规范](https://developer.apple.com/design/human-interface-guidelines/branding)

## 公共画布实测

| 编号 | SceneTurn 中的操作和核对结果 |
| --- | --- |
| A01、A02 | 从工具栏或空白处打开菜单，新建文本、脚本、图片、视频、音频、剪辑或导演台。单击卡片正文或标题可打开编辑器。点空白关闭后，再点卡片继续编辑原草稿。 |
| A03、A04、A05 | 实际测试从端点点选或拖向空白处创建下游，从输入端反向连接已有节点并保存。1280 和 1440 像素视口分别测量了曲线起止坐标、卡片边缘、端点中心以及悬停时的变化。画布参考可连续选材，点击「完成选择」返回生成器。 |
| A06、P10、P11 | 直接拖动平移视角，长按卡片后拖动调整节点位置。按住 Shift 拖动空白处可框选。缩放菜单支持手动输入百分比和适配画面。点阵基准间隔为 16 画布单位。 |
| A07、P02、P03 | 实际上传一份文本并保存，打开版本记录读回正文，另以指定名称和文件夹保存到资产库。通过类型、关键词和网格视图定位节点，刷新后正文仍在。版本和项目资产由后端按当前用户读取。 |
| A08、P01、P07 | 将所选节点发送至当前项目和场景的创作对话，核实引用名称，修改对话标题并读回。验证了故事板素材分类及返回工作流。 |
| P04 | 生成历史按当前项目实际媒体筛选。用于添加参考时保留目标节点和媒体类型检查，选错时可重新选择。独立的 LibTV 历史窗口缺少完整参考图。 |
| P05、P06 | 实测填写角色名称和服装并保存角色卡，从「全部功能」搜索裁切并打开素材选择。相同操作使用画布中已有的媒体处理工具。具体支持的处理类型见图像、视频和音频核对记录。 |
| P12 | 检查了教程菜单和本机教程页面的响应。帮助与反馈使用 SceneTurn 的入口。 |

两项公共画布测试均在隔离账号的生产构建通过。测试使用真实项目存储，未提交收费生成。[节点、资产与对话测试](../../frontend/tests/browser/canvas-browser-tools.spec.ts) · [连线几何和保存测试](../../frontend/tests/browser/canvas-reference-links.spec.ts)

## 文字与脚本组件

| 编号 | SceneTurn 中可检查的行为 | 核对依据与限制 |
| --- | --- | --- |
| B01 | 空文本卡点击「自己编写内容」，或双击正文，即可原地输入。 | 原图中新建方卡为 350 × 350 画布单位，四个入口位于卡片内部。 |
| B02 | 选择文字模型、编辑要求、排序和点名参考、翻译。生成走项目已有文字服务和费用记录。 | 按源稿保留参考区、正文和底部动作。界面使用项目实际接入的模型名。 |
| B03 | 文生视频和文字生音乐各创建一个相连的下游，焦点切到新节点。 | 原图可核对两项入口，生成供应商由项目配置决定。 |
| B04 | 反推操作从 LibTV 同一预设取得图片，存入当前项目，建立上游节点并写入可编辑要求。 | 当前千问接收项目所属的真实图像；DeepSeek Flash 的接入接收文字。 |
| C01 | 剧本入口加入上游文字，角色入口加入两张原预设角色图。用户可以接着修改要求。 | 新建空卡按原图使用方形，已填镜头表为 800 × 400 预览。 |
| C02 | 手工镜头在「确认镜头 → 准备资产 → 合成提示词」中编辑，行标识和字段随项目保存。 | 按十列原图核对初始行、时长、画面、景别、光影、声音、运镜和底部区域。 |
| C03 | 用户可从画布、本机文件、项目素材库选择图片，取消素材库选择，移除或调整参考的顺序。 | 排序同样改变实际连线顺序；项目素材权限仍由服务端校验。 |
| C04 | 选定若干镜头后，分别建立图像或视频制作卡。视频读取该镜的剧本、分镜图和时长，提交前可在各卡核对规格。 | 完成实际提交后，费用与供应商结果应在任务记录中核验。 |
| C05 | 新版打开分步镜头表，旧版使用独立表格。历史行继续保留动作、对白和画面。 | 版本保存在节点元数据，已有「脚本（旧版）」卡可继续打开。 |

在 1600 × 1100 桌面浏览器中，4 项文字和脚本用例以及既有的端口连线用例全部通过。测试从注册及新建项目进入，完成原地写作、创建视频和音乐节点、切换文字模型、选择与取消图片、上传与排序、生成两个独立分镜图任务、保存旧版镜头表。逐镜验证从服务端读回首帧引用、4 秒时长和对应剧情，刷新后再次打开镜头表读回同一内容。文本结构和提示词专项测试 14 项通过。本轮未发起供应商收费生成，模型译文、反推结果和画面质量待实际生成核验。[浏览器用例](../../frontend/tests/browser/canvas-text-script.spec.ts)

# SceneTurn 桌面页面与 Figma 核对

当前首页原型及逐段用途说明见 [首页用途与交互](首页用途与交互.md)。

与黑白首页搭配的项目、编辑、素材和模型设置，见 [创作台黑白设计](../SceneTurn创作台/创作台设计说明.md)。

[Figma 首页对照](https://www.figma.com/design/hZks5Vdjpak1GtnPe65bvc) · [可编辑本机文件](SceneTurn首页对照.fig)

设计稿首个页面记录首页设计依据与 SceneTurn 首页的布局。首页依次介绍产品定位、互动短片体验、公开作品、创作流程和常见问题。第二个页面展示两种选择结果，先导片与互动图层说明播放体验。

核对对象是[原桌面设计](../SceneTurn桌面设计/设计说明.md)的 41 张画板。公开页面及登录注册通过本机浏览器检查。需登录、已发布版本、生成回执或指定素材状态的画板结合当前路由、组件和阶段浏览器记录核对。这里记录页面结构、入口、控件和状态，屏幕尺寸按 1440 像素桌面窗口。

## 项目、剧情与剪辑

| Figma 画板 | 当前入口 | 对应情况 |
| --- | --- | --- |
| 项目工作台 | 项目页 | 有创建、编辑和试玩。本轮加入可直接点击的素材库、作品馆入口。最近项目大封面、搜索和视图切换待对应。 |
| 完整项目导入 | 项目页 → 导入与恢复 | 支持 ZIP 预检、映射和确认。当前为折叠区域，画稿使用独立分栏预检。 |
| 剧情总画布 | 编辑器 | 有自由画布及工具栏。左侧常驻场景列表、右侧固定属性与缩略图卡待对应。 |
| 剧情画布与 Codex | 编辑器 → 问问 AI | 真实配对和对话使用右侧覆盖栏。画稿采用占布局宽度的分栏。 |
| 节点时间线 | 编辑器 → 节点 | 实际上部是资源、监视器、属性三栏。画稿简化为监视器与属性，轨道工具位置也不同。 |
| 时间线 · QTE | 时间线 → QTE | 有按键、成功和失败跳转。独立的响应时间、结果摘要和预览入口待对应。 |
| 固定版本与发布 | 编辑器 → 导出 | 已提供固定版本、状态、公开和撤下。当前为弹窗作业卡，画稿为完整发布页面。 |
| 登录 SceneTurn | 登录页 | 登录主流程已接通。本轮修正外框、密码显隐和页尾入口。 |
| 创建 SceneTurn 账号 | 登录页 → 创建新账号 | 注册已接通。本轮区分注册与登录画面。 |

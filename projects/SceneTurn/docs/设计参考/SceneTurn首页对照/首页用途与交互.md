# SceneTurn 首页用途与交互

[Figma 首页与互动试玩](https://www.figma.com/design/1yAfX7nImYlNHvbRyegJ78?node-id=0-1) · [Figma 首页动效](https://www.figma.com/design/1yAfX7nImYlNHvbRyegJ78?node-id=0-3)

桌面设计以 1440 × 900 为演示尺寸。首页用同一部原创互动样例《潮汐尽头》，让访问者认识产品、体验观众选择，再查看创作者怎样制作这段作品。

| 位置 | 内容与操作 |
| --- | --- |
| 顶部导航 | 左侧显示标志和产品、功能入口，中央显示菜单和进度，右侧可进入创作台。 |
| 首屏 | 「让观众决定下一幕」说明产品用途。右侧展示《潮汐尽头》剧照，左侧提供仓库和创作入口。 |
| 产品介绍 | 说明如何生成素材、用个人 Codex 编排剧情及添加互动。左右分别展示实际素材对话与「问问 AI」和剧情蓝图。 |
| 互动试玩 | 访客可为《潮汐尽头》分配备用电。两项选择分别进入不同结局，结局页可重新选择或返回首页。 |
| 工作台预览 | 左侧四行可点击或用键盘选中，右侧查看同一项目的剧情画布、互动时间线、网页播放器和素材库。 |
| 创作流程 | 依次介绍导入素材、编排剧情、添加互动、试玩与发布。 |
| 常见问题与页尾 | 默认展开「可以用手头的素材开始吗？」。其余问题说明模型配置、Codex 配对和权限、网页游玩及发布范围。页尾提供创作台与 GitHub 的入口。 |

## 演示中可核对的操作

1. 从首屏向下滚动，或点导航的「产品」。左栏素材截图里可见总编与各制作岗位以及待发送的生成需求。右栏展示同一项目的剧情蓝图和待发送的分支、按钮要求。两张截图均为实际工作台，Codex 示例处于待连接状态。
2. 从产品段的「体验观众选择」到达试玩区域，点「开始试玩」。分别选择「点亮信标」和「关闭闸门」，核对两个结局和「重新选择」。
3. 回首页点「功能」，逐项切换剧情画布、场景与互动、网页试玩和项目与素材，核对同一项目的四张实际工作台画面。时间线与播放器显示实际的按钮和分支结果。
4. 向下滚动至常见问题，打开一个问题，再点当前问题将它收起。「查看模型设置」通往本机工作台的模型设置。
5. 点顶部「菜单」可进入创作台或打开 GitHub。

《潮汐尽头》的 Figma 试玩通过剧照、情节文字和分支跳转演示选择结果。成片及触发时机留给实际作品。

首屏、试玩和顶部导航使用黑底白字，右上「进入创作台」与中央菜单采用相同的深灰底、白字和灰色描边。产品能力、功能一览和常见问题使用白底黑字，灰色用于辅助文字和分区。功能选中状态同时显示黑边和勾选图标。剧照和实际工作台截图保留原色。

本机原型回读验证覆盖界面灰阶色值、精简后的顶部菜单、四个功能选中状态、六种问答展开状态、章节入口和两条试玩分支。九个图像资源与上一版一致。

## 正式网页动效与操作

| 位置 | 触发与表现 | 减少动态效果 |
| --- | --- | --- |
| 固定导航 | 阅读比例取当前滚动距离除以全页可滚动距离。菜单按 Escape 或点击外侧关闭，关闭后焦点回到菜单。产品、功能入口直接跳转至对应段落 | 直接跳转，百分比按实际位置更新 |
| 首屏到产品 | 前 420 像素滚动中，成品图在 0.94 到 1 倍之间改变，位移上限 24 像素。标题和入口保持可读，第一段正文进入视口后由 12 像素下方淡入，时长 220 毫秒 | 静态画面，区域内容直接显示 |
| 产品能力和功能预览 | 两张能力卡片达到 35% 可见时出现，第二张延迟 80 毫秒。功能行悬停反馈 140 毫秒，用户点按后选中状态立即更新，右侧实际画面 180 毫秒淡换。键盘可聚焦并切换功能 | 内容直接显示，保留选中状态和即时预览 |
| 试玩与剧情切换 | 由访客主动开始。选中后先确认按钮状态，再切换到目标场景，转场约 200 毫秒。重玩时恢复选择点 | 保留选择状态，即时换场 |
| 常见问题 | 整行可用指针、Enter 或空格切换，约 200 毫秒展开。当前问题可收起，展开另一项时关闭前一项。控制箭头、可见内容、焦点和展开状态同步 | 立即展开或收起，保留同样的键盘操作 |

Figma 的「正式前端动效」页包含首屏、首次下滚和继续阅读的关键状态。演示模式的菜单百分比为示意，实时进度和随滚动变化的动效在正式网页实现。实际交互和减弱动效的设计依据见 [Apple 动效规范](https://developer.apple.com/design/human-interface-guidelines/motion) 和 [Apple 减少动态效果标准](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)。

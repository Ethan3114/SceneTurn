从「桌面原型目录」进入常用流程，或点「浏览所有界面与状态」检查各岗位、异常和权限。主界面按 1440×900 绘制，窄桌面画布示例为 1280×900。共 192 个原型画板，其中 13 个为评审目录与索引。文件包含可编辑的文字和矢量层，原型使用《裂盏》实际成片的三个预览画面。

## 评审路径

1. 在「账户与项目」打开《裂盏》。检查注册、登录、项目创建、完整导入、缺失文件和重复导入。
2. 进入「剧情与时间线」。在故事画布点「夜试斗气」进入时间线，查看视频裁切、互动按钮、QTE 和分支设置。在「本人 Codex」检查配对、停止、恢复和项目版本冲突。
3. 进入「素材制作」。在问问 AI 核对总编的澄清问题，依次采用剧本、角色与场景图、有序分镜。核对视频卡显示本段剧本、规格和首尾图，经同意才进入生成中。视频完成后从候选采用到时间线。也可查看提交待核实、原任务查询、确认重试和改稿。
4. 进入「网页试玩」，从开场走到选择点，分别查看「稳住斗气」和「裂盏失手」。试玩、已保存网页、固定版本及公开版本各有入口，公开访问和撤销同步纳入设计。
5. 在「备份与发布」和「生成设置」检查固定版本、发布范围、备份、各生成服务、用量和权限。普通素材对话显示需求、状态、确认和可交付成果。内部提示词、工具参数和供应商价格由获授权的开发入口查看。

Figma 点击用于预览页面与状态变化。原型使用静态视频预览图，供应商提交、真实播放、计时、键盘行为和服务端权限在产品代码中验收。

已在 Figma 中打开设计稿并启动演示。实点验证路径包括素材需求、总编澄清、依次采用剧本、角色场景图及分镜、确认视频、查看成品、采用候选到时间线，以及网页试玩的两条分支。重新读取本机 `.fig` 已核验 192 个画板、2201 条点击连线和 5150 个独立文字层，全部画板可从评审目录进入。

## Apple 桌面设计要求

| 规范 | 本项目的设计与验收要求 |
| --- | --- |
| 分栏和导航 | 同时显示任务需要的内容。领先侧栏用于项目与场景，工作内容在中间，检查器和对话可从工具栏收起和恢复。窄窗口优先保留画布与主要操作。 |
| 工具栏 | 按导航、当前内容和常用动作组织控件。当前选择有形态或文字提示，次要命令可归入更多菜单。 |
| 字体与可读性 | 原型使用 Noto Sans SC，桌面网页沿用系统字体优先及中文后备。正文默认 14，辅助文字通常为 12。操作目标不小于 28×28，焦点有可辨识描边，常规文字对比度目标为 4.5:1。 |
| 焦点与快捷键 | 保留键盘顺序和焦点可见性，弹窗关闭后恢复到触发控件。画布敏感操作有菜单选项，拖动有键盘或字段替代。 |
| 确认与进度 | 等待、失败和恢复在相关区域反馈，说明影响与下一步。用户提交视频、发布或永久删除时能看见结果与取消选项，展示中只允许操作当前确认层。 |

已对正文、辅助文字、焦点、选中项、主要按钮和删除按钮的配色计算对比度，所核对组合为 5.47:1 至 16.43:1。原型文件检查了点击区域尺寸和画板边界。

依据为 [macOS 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[分栏视图](https://developer.apple.com/design/human-interface-guidelines/split-views)、[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[表单弹窗](https://developer.apple.com/design/human-interface-guidelines/sheets)、[警示框](https://developer.apple.com/design/human-interface-guidelines/alerts)、[键盘](https://developer.apple.com/design/human-interface-guidelines/keyboards)、[字体](https://developer.apple.com/design/human-interface-guidelines/typography)及[无障碍](https://developer.apple.com/design/human-interface-guidelines/accessibility)。

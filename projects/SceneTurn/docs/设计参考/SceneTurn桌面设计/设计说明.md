# SceneTurn 桌面设计

[Figma 设计稿](https://www.figma.com/design/M9ZSQNYyTmMeUPFH6Qh4Yq?node-id=0-1) · [本机可编辑文件](SceneTurn桌面设计.fig) · [画板索引](coverage.json)

SceneTurn 是互动影像创作平台。字标旁由两段斜切胶片组成 S 形，切口借用影片剪接的形态。图标使用暖金和浅米色的可编辑矢量。影院使用暖金色标记主要操作和播放进度，创作台使用紫色标记主要操作、选中项与键盘焦点。工作台沿用 Apple HIG 的导航、工具栏、分栏和确认规则。

首页以《潮汐尽头》先导片展示电影画面，提供「播放先导片」入口。作品详情的「进入影院」对应可游玩固定版本。角色交谈画板展示玩家在影院打开对白、选择回复或返回剧情的方式，具体角色互动作品由创作者制作。当前交付包含可编辑的静态画板、播放器状态示意和四张原有原创剧照。实际先导片需在运行产品中接入视频媒体。

## 素材制作的后续方向

左侧以可自由平移和缩放的无限画布为主。项目里的全部素材都可作为独立节点放置、移动和连线，包括剧本、角色图、场景图、分镜、视频和声音。画布保存素材位置和已采用的连接，供创作者继续整理。

右侧通过对话理解当前制作意图，从项目素材中找出需要的版本，展示推荐用途及可能的连线。选中一条建议时，在左侧定位相关素材，用虚线预览建议连接，采用后再保存成正式连线。MVP 继续采用岗位成果区和素材对话，另有「手动编辑画布」入口。
